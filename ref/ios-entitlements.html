iOS Entitlements Reference

Entitlement keys granted through the provisioning profile and code signature. Enable them in Xcode under Signing & Capabilities; they are stored in the app's .entitlements file.

How entitlements work: an entitlement only takes effect when it appears in both the app's code signature (the .entitlements file) and the provisioning profile — which requires the matching capability enabled on the App ID in the Apple Developer portal. A mismatch is the classic cause of install error 0xE8008016 ("provisioning profile doesn't include entitlement"). Inspect a built app's entitlements with: codesign -d --entitlements - MyApp.app. Apple approval — the capability must be requested from Apple at developer.apple.com and granted before it appears in your account. Auto-added — injected by Xcode / the signing process; you never add it to the .entitlements file yourself. EU only — available only for apps distributed in the European Union under the Digital Markets Act.
